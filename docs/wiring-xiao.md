# מפת חיווט XIAO — הופנתה למדריך לאחר הביקורת

2026-11-09: מפת החיווט הקודמת נמשכה משימוש. פיני השבב TXB0104 אינם מפת המודול NOYITO שנרכש, ואין עדיין מיפוי חשמלי מאומת לשני המתאמים.

[המדריך עם תמונות וחוטים](assembly/RooCore-assembly.html) · [הוראות Markdown](assembly/README.md) · [ביקורת הרכיבים](assembly/MODULE_AUDIT.md) · [קובץ הפריטים](../HARDWARE_INVENTORY.md).

הפינים שאומתו מול Seeed לשלבי ההכנה: 5V/VBUS, ‏GND ו־D3/GPIO4 לבקרת ON של Pololu #2810, וכן D4/GPIO5 ו־D5/GPIO6 ל־UART של הליידר. פין 3V3 הוא יציאה ונשאר פנוי; BAT אינו בשימוש. לפני USB מנתקים את כל הצמה, כולל אותות. הוראות ההכנה ותנאי הבדיקה מפורטים בחוברת, ואין עדיין חיבור לסוללת הרומבה.

הביקורת החוזרת עם electronics ו־esp32-development: [מפות רגליים, חישובי הספק, ומה נשאר לבדיקה](assembly/ELECTRICAL_REVIEW.md). הסקילים נטענו; אין להמשיך להשתמש בהודעה הישנה שהם לא נמצאו.

עדכון גרסה 4: **D4/GPIO5 → LiDAR RX; LiDAR TX → D5/GPIO6**. חוטים 12–13 נשארים מחוברים; הקושחה מורידה את האותות לפני כיבוי S1. [החיבור, הקוד ותנאי הבדיקה](assembly/LIDAR_POWER_UART.md). אין רכיב נוסף לנתיב הזה.
