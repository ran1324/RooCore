# התרשימים הקודמים נמשכו משימוש

2026-11-09: אין להשתמש בתרשימים הישנים להרכבה. הם התבססו בחלקם על פיני שבב ולא על המודולים שנרכשו. הקבצים הוחלפו בכרטיסי הפניה כדי שקישור ישן לא יחזיר חיבור שבוטל.

[המדריך עם תמונות וחוטים](../../assembly/RooCore-assembly.html) · [קובץ draw.io הפעיל](../../assembly/RooCore-assembly.drawio) · [ביקורת הרכיבים](../../assembly/MODULE_AUDIT.md).

החיבורים הפעילים הם הכנות ללא מתח, עם תנאים בכל שלב. אין עדיין תרשים סופי לחיבור לסוללה. [הארכיון שנמשך משימוש](../../assembly-history/2026-11-09-withdrawn-before-module-audit.zip) נשמר לצורך מעקב בלבד.

ביקורת חוזרת עם electronics ו־esp32-development: [מפות רגליים, חישובים ובדיקות השלמה](../../assembly/ELECTRICAL_REVIEW.md). [הסכמה החשמלית הפעילה](../../assembly/electrical-schematic.svg) מציגה אותם 13 חוטים שבטבלה, עם מספרים אחידים ופינים שנשארים ללא חוט.

עדכון גרסה 4: **D4/GPIO5 → LiDAR RX; LiDAR TX → D5/GPIO6**. חוטים 12–13 נשארים מחוברים; הקושחה מורידה את האותות לפני כיבוי S1. [החיבור, הקוד ותנאי הבדיקה](../../assembly/LIDAR_POWER_UART.md). אין רכיב נוסף לנתיב הזה.
